# Campus Lost and Found FAQ Chatbot

A Python chatbot that answers campus lost and found questions using a fixed FAQ knowledge base. When the FAQ does not contain an answer, the chatbot directs users to the college helpdesk.

This is a **class project**, not an official Lady Doak College service or policy.

## Run in Google Colab

1. Open `CAMPUS_LOST_AND_FOUND_FAQs.ipynb` in Colab.
2. Add your Gemini API key to Colab Secrets with the name `GEMINI_API`.
3. Run the cells in order and ask a question. Type `quit` or `bye` to exit.

Built with Python and the Google Gen AI SDK. Never add your API key to the notebook or repository.
